# Contributing

Start with a small issue or pull request explaining the behavior you want to change. Feature requests and discussions are welcome; acceptance and support are best effort. Use fictional data in reproductions. Never attach customer files, access tokens or extracted portfolio cases.

Run `npm ci`, `npm run check`, `npm test` and `npm run build`. Inspect affected desktop and mobile flows. Use `DECK_STUDIO_BUILD_DIR` when your checkout's `dist` is a protected snapshot. Document external-provider and native-device limitations instead of claiming untested conversion fidelity.

Code contributions are accepted under MIT. Project-original decorative assets use CC0; third-party assets require their own compatible license, full notice and source evidence. AI-assisted contributions are welcome: review the output, check dependencies and rights, and describe the assistance in the pull request. Generated code is not proof that all third-party rights are cleared.

By submitting a contribution you confirm that you have the right to submit it under the indicated project license and that it contains no confidential material. Keep copyright notices and attribution. No CLA or copyright transfer is required. Respect others, focus feedback on the work, and don't post personal information.
