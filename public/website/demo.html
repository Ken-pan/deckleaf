Try the complete workflow

  1. Open the sample. A fresh three-slide copy is saved in this browser. Read and close the import report.
  2. Edit. Rename the document in the top bar. Select text and choose Edit text, or double-click it to change; click outside to finish.
  3. Present. Choose Present and use the arrow keys. Escape returns to editing.
  4. Keep a copy. Document menu → Export document → Deck file downloads an editable backup. PowerPoint and Web page make sharing copies.
