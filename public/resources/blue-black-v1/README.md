# 蓝黑插图库 · v1.2

为产品设计作品集与 PPT 生成的 204 张 raster PNG：92 张场景、12 张人物、100 张小插图。由内置 imagegen 生成，采用已确认的干净蓝黑风格。

## 取用

双击 index.html 可离线浏览、搜索、按主题筛选与下载 PNG。在本地服务打开时，浏览器支持的情况下可复制图片；file:// 下使用 PNG 下载或从 png 文件夹拖入。PNG 压缩包按当前筛选在浏览器中生成。

- 场景 1536 × 1024；人物 1024 × 1536；小插图 1254 × 1254。保留原始像素与透明通道。
- 透明背景，白色人物与对象内部保留白色填充。生成输出包含少量半透明边缘，适用范围为白色与浅色底；深色版面建议使用白色容器。
- 场景建议宽 320–720 px，小插图 96–160 px。原比例缩放；这些是本套使用建议，并非行业统一标准。
- 一页一个主要叙事场景；标题、数字、标签与证据在幻灯片中独立排版。
- 不拉伸、不切掉人物手脚、不加阴影或渐变；沿用蓝黑白，保留外部留白。
- 装饰插图使用空 alt；图片确实传达信息时，从 manifest 的 alt 开始，再按上下文调整。

## 如何扩展

参考图为 references/style-master.png。prompts.json 保存本套完整提示词；manifest.json 保存稳定 ID、主题、中英关键词、建议描述、文件路径、尺寸、哈希与来源。新增资产保留同一母图与风格约束，只改场景，先生成一张检查再扩展。新版本使用新文件名/目录，保留已经使用的旧素材。

每张生成后检查：主体与动作是否清楚、手与道具是否合理、线条与蓝黑比例是否一致、透明边缘与白色填充是否合适、缩小到目标尺寸是否可读。不要把生图视为可编辑矢量组件；本套复用依靠独立 PNG、统一布局与稳定检索信息。

## 研究依据与本套取舍

- [GitLab — Creating illustrations](https://design.gitlab.com/product-foundations/illustration-creation-guide/)：统一填色、线条、尺寸层级与无内嵌文字；尺寸数值按本套 raster 素材重新定义。
- [GOV.UK — Images](https://design-system.service.gov.uk/styles/images/)：用最少元素解释信息，统一风格；装饰使用空 alt，传达信息时使用简洁含义描述。
- [Atlassian — Illustrations](https://atlassian.design/guidelines/brand/illustrations/)：按语境选图；用 spot 支持状态、章节与轻量概念。
- [Carbon — Pictograms guidelines](https://www.carbondesignsystem.com/building-blocks/foundations/pictograms/guidelines)：保留留白、光学居中、等比例缩放；小插图作为插图使用，不承担 UI 操作图标职责。
- [Carbon — Empty states](https://www.carbondesignsystem.com/building-blocks/core/patterns/empty-states)：补齐首次使用、无内容、权限、系统问题与恢复路径；具体场景为本套用途选择。
- [Sensor Tower — State of Mobile 2026](https://sensortower.com/blog/state-of-mobile-2026)：AI 与跨行业服务提供热点方向；不将行业增长等同于本套场景的使用排名。
- [Sensor Tower — State of AI 2026](https://sensortower.com/blog/state-of-ai-2026)：AI 扩展到健康、财务、教育等领域，补充具体人机协作与服务情境。
- [NN/g — Explainable AI in Chat Interfaces](https://www.nngroup.com/articles/explainable-ai/)：把 AI 输出来源核验与人工编辑画成不同情境，避免万能机器人隐喻。
- [Baymard — Ecommerce UX Insights 2026](https://baymard.com/research-articles/ecommerce-quantitative-ux-insights-2026)：补齐订单跟踪、退货与支付恢复；现有购物推荐场景不足以覆盖履约。
- [Microsoft — Human Rights Transparency Report 2025](https://cdn-dynmedia-1.microsoft.com/is/content/microsoftcorp/microsoft/msc/documents/presentations/CSR/Human-Rights-Transparency-Report-2025.pdf)：补充朗读/辅助阅读场景，不将插图视为产品无障碍验证。
- [Google PAIR — People + AI Guidebook](https://pair.withgoogle.com/guidebook-v2/chapters)：按输入、输出、反馈与控制、解释与信任、失败恢复建立覆盖；不是场景热度排序。
- [Microsoft — HAX Toolkit](https://www.microsoft.com/en-us/haxtoolkit/)：把常见人机互动和失败路径画成可理解、可纠正的用户情境。
- [NN/g — AI Agents as Users](https://www.nngroup.com/articles/ai-agents-as-users/)：补充 Agent 的计划、工具边界、执行进度和人工介入；插图不证明实际系统可靠。
- [Carbon data-table guidelines](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines)：Row selection, batch scope, filtering, and data operations
- [Retool administration quickstart](https://docs.retool.com/org-users/quickstart)：Team roles, administration, permissions, and audit records
- [Jira Service Management queues](https://support.atlassian.com/jira-service-management-cloud/docs/how-are-queues-used-in-jira-service-management/)：Request triage, queue priority, and assignment
- [Microsoft HAX design patterns](https://www.microsoft.com/en-us/haxtoolkit/design-patterns/)：AI capability communication, uncertainty, correction, and recovery
- [Atlassian IT service management guide](https://www.atlassian.com/collections/service/guides/it-service-management)：Service requests, change delivery, deadlines, and operational workflows

场景覆盖、人物动作、主题清单、透明 PNG 与检索面板是针对本次作品集/PPT用途的设计选择。未复制这些设计系统的插图素材。
